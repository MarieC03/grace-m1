.. _grace-citing:

Citing
========

If you use GRACE in your work or publications, please cite the GRACE code
paper, *GRACE: An Open-Source Framework for GPU-Accelerated Numerical
Relativity* (`arXiv:2607.09854 <https://arxiv.org/abs/2607.09854>`_).

Authors and contributors are listed in the top-level ``AUTHORS`` file in
the repository.
